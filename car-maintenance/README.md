# 그붕이 정비 계기판

그랜저 IG 3.3(2017-10 출고)의 소모품 11개 품목을 **시간 주기와 주행거리 주기 중 먼저 오는 쪽**으로 판정하는 claude.ai 아티팩트의 소스와 운영 구조다.

- 아티팩트: https://claude.ai/artifact/Tk6srnKHJefj3i9qXZvRq3 (비공개)
- 소스: `gbung-dashboard.html`
- 데이터 정본: Vault Family `28. 자동차/10. 그붕이/10. 소모품/01. 소모품 교체 기록표`. 아티팩트는 운영용 사본이다. 교체를 기록한 뒤 화면의 「기록표 마크다운 복사」로 정본에 반영한다.

```
             ▼                                          ▼
  아티팩트 DB (items · odo · history · settings) ◀── 주간 점검 루틴 (월 08:52 KST)
             │                                          │
             ├─ 품목 카드 「캘린더 알림」 → Google Calendar 09:00 일정
             └─ 판정: 🔴 지금 / 🟡 확인 / 🟢 여유 / 상태 기준          └─ 🔴·🟡 있으면 푸시·메일
```

## 판정 규칙

| 항목 | 계산 |
|---|---|
| 하루 주행량 | 최근 400일 주행거리 기록의 최소제곱 기울기. 기록이 부족하면 18.3 km/일 |
| 오늘 추정 주행거리 | 마지막 기록 + 하루 주행량 × 경과일 |
| 시간 예정일 | 마지막 교체일 + 주기(개월) |
| 거리 예정일 | (마지막 교체 km + 주기 km − 추정 주행거리) ÷ 하루 주행량 → 날짜 환산 |
| 다음 교체일 | 두 예정일 중 이른 쪽 (카드에 「시간 기준」/「거리 기준」 표시) |
| 🔴 지금 | 예정일 경과, 잔여 km ≤ 0, 또는 수동 판정 「지금」 |
| 🟡 확인 | 남은 일수 ≤ 선행일(기본 30), 잔여 km ≤ 선행 km(기본 1,000), 또는 수동 판정 「확인」 |
| 상태 기준 | 주기 값이 없는 품목(브레이크패드 잔량, 스마트키 건전지) |

## 주행거리 수집 — MacroDroid

웹훅 주소는 아티팩트 화면의 「주행거리 자동 수집 · 알림 구조」에 있다(공개 저장소라 여기에는 적지 않는다).

### 방식 A — 입력 대화상자 (권장)

1. 트리거: 요일/시각 — 일요일 20:00
2. 동작: 대화상자 - 텍스트 입력 → 숫자 키패드, 결과를 지역 변수 `odo`(정수)에 저장
3. 동작: HTTP 요청 — POST, 웹훅 주소, Content-Type `application/json`, 본문
   `{"km": "{lv=odo}", "date": "{year}-{month_digit}-{dayofmonth}", "source": "macrodroid"}`
4. 동작: 알림 표시 — 「그붕이 {lv=odo} km 전송」

### 방식 B — 마이현대 화면 읽기 (블루링크 가입 시에만)

마이현대 홈의 「총 주행거리」는 블루링크(커넥티드 카) 모뎀이 보낸 값이다. 2017-10 등록 차량은 무료 5년이 2022-10에 끝났으므로 유료 가입이 살아 있어야 값이 갱신된다.

1. 애플리케이션 실행: 마이현대 → 대기 8초
2. 화면 내용 읽기 → 사전 변수 `scr`
3. 텍스트 조작: 정규식 추출 `([0-9]{1,3},?[0-9]{3})\s*km` (그룹 1) → 쉼표 제거 → `odo`
4. 방식 A의 3·4단계

제약: 접근성 서비스 활성, 화면 켜짐·잠금 해제 상태 필요. 앱 업데이트로 화면 구조가 바뀌면 정규식·대기 시간을 다시 맞춘다.
