# 주차 자동 기록 — 시동 꺼짐·켜짐 짝짓기

> 작성: 2026-10-10 (KST). 주차 1건은 **시동 꺼짐(BT 끊김) 시각부터 다음 시동 켜짐(BT 연결) 시각까지**다.

## 왜 안 됐나

- 기록은 MacroDroid 알림을 사람이 눌러 페이지가 열릴 때만 만들어졌다. 누르지 않으면 꺼짐·켜짐 둘 다 사라졌다.
- 그 결과 DB 5건이 전부 수동 입력이다. 자동 기록은 0건이다.

## 규칙

| 이벤트 | 하는 일 |
|---|---|
| BT 끊김 (시동 꺼짐) | 주차 시작. `p<꺼진 ms>` 기록을 연다 |
| BT 연결 (시동 켜짐) | 열려 있는 주차를 이 시각으로 닫는다 |

## 예외

- **꺼짐 → 켜짐이 3분 미만**: 신호가 잠깐 끊긴 것으로 보고 무시한다.
- **꺼짐이 두 번 연속**(켜짐 누락): 앞 주차를 두 번째 꺼짐 시각에서 닫고 `추정 종료`로 표시한다.
- **켜짐만 있음**(꺼짐 누락): 버린다.

## 구성

1. **폰(MacroDroid)**
   - 지정한 차량 기기의 BT가 끊기면 `ms,OFF,위도,경도`를 `parking_log.csv`에 덧붙인다.
   - 다시 연결되면 `ms,ON`을 덧붙인다.
   - 파일은 Autosync로 Drive에 올라간다. 알림을 누를 필요가 없다.
2. **서버**
   - 루틴(하루 4회, Drive 커넥터)이 위 규칙으로 꺼짐·켜짐을 짝지어 DB에 쓴다.
   - 페이지를 열 때도 같은 로그를 읽어 바로 반영한다.
   - id가 `p<꺼진 ms>`라 같은 이벤트를 다시 처리해도 기록이 중복되지 않는다.
3. **감시**
   - BT 이벤트가 72시간 넘게 없으면 "로그 끊김"을 알린다.
