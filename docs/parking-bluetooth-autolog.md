# 주차 자동 기록 — 시동 꺼짐·켜짐 짝짓기

> 작성: 2026-10-10 (KST). 주차 1건은 **시동 꺼짐(BT 끊김) 시각부터 다음 시동 켜짐(BT 연결) 시각까지**다.

## 왜 안 됐나

- 기록은 MacroDroid 알림을 사람이 눌러 페이지가 열릴 때만 생겼다. 누르지 않으면 꺼짐과 켜짐이 모두 사라졌다.
- 그래서 DB 5건이 전부 수동 입력이었다. 자동 기록은 0건이었다.

## 구조

```
[차량 BT 끊김/연결] → 두 사람 폰의 MacroDroid 「주차 BT 기록」 → Documents/parking/parking_log_<사람>.csv (추가 모드)
                                   │ Autosync (업로드)
                                   ▼
                          Drive 주차 로그 폴더
              ┌────────────────────┴───────────────────┐
     페이지가 열릴 때 (mcp: Google Drive 읽기)     루틴 하루 4회 (node parking_sync.js)
              └────────────────────┬───────────────────┘
                                   ▼
                      주차 DB parkings · sync/state
```

같은 반영 코드(`parking/parking_sync.js`)를 페이지와 루틴이 함께 쓴다.

## 로그 형식

`YYYY-MM-DD,H:MM,OFF|ON[,위도,경도]` (KST, MacroDroid 매직 텍스트)

## 규칙

| 이벤트 | 처리 |
|---|---|
| 꺼짐 | 주차 시작. 기록 id는 `p<꺼진 시각 ms>` |
| 켜짐 | 열린 주차를 이 시각으로 닫는다 |
| 꺼짐 → 켜짐이 3분 미만 | 버린다 (신호 끊김) |
| 막 꺼진 지 3분 미만 | 다음 실행으로 미룬다 |
| 꺼짐이 연속 2번 | 앞 주차를 두 번째 꺼짐 시각에 닫고 `추정 종료`로 표시한다 |
| 켜짐만 있음 | 버린다 |
| 시작 ±20분 안에 수동 기록이 있음 | 새로 만들지 않고 그 기록에 좌표·BT 시각만 채운다. 층·메모·손으로 넣은 출차 시각은 보존한다 |
| 두 폰이 5분 안에 같은 꺼짐·켜짐을 남김 | 같은 사건으로 보고 1건으로 합친다 (둘이 같이 탄 경우) |
| 한 폰의 로그가 늦게 올라옴 | 폰마다 따로 어디까지 처리했는지 기억한다(`sync/state.lastBySrc`). 앞 시각 운행도 반영한다 |
| 열린 기록 뒤에 시작한 기록이 있음 | 차는 한 대이므로 앞 기록을 뒤 기록 시작 시각에 닫는다 (추정 종료) |
| 무료 장소(`free`) 안에서 꺼짐 | 기록은 남기되 시간·요금을 세지 않고, 월 통계·미출차 알림에서 뺀다 |
| 이미 처리한 이벤트 | 다시 처리하지 않는다. 지운 기록을 되살리지 않는다 |
